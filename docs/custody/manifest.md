## 2. Digital Signing & Verification

1. **Signature Algorithm:** HMAC-SHA256 (keyed via `MANIFEST_SIGNING_KEY` environment variable).
2. **Canonical Payload:** Computed across all manifest fields with `digital_signature` and `storage_uri` excluded.
3. **Verification Method:** `verify_manifest(manifest_dict, key)` provides constant-time comparison to prevent timing attacks.
