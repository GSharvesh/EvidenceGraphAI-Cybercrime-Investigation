# ADR 0006: Open Source Licensing Strategy (Apache 2.0)

## Status
Accepted

## Context
EvidenceGraphAI is designed as an open enterprise multi-agent cybersecurity framework. The license choice must permit commercial, academic, and government adoption while granting patent rights and explicit non-endorsing conditions.

## Decision
We choose the **Apache License, Version 2.0**.

## Consequences
- Allows permissive use, modification, and distribution.
- Includes explicit grant of patent rights from contributors.
- Protects the project name and trademarks.
